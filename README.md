# لمسة ورد — Lamsat Ward

موقع صالون نسائي (فرونت إند فقط). الحجوزات والإدارة تُحفظ في المتصفح.

## التشغيل

```sh
npm i
npm run dev
```

افتح الرابط الذي يظهر في الطرفية.

حساب الإدارة: `admin` / `222`

## الصفحات

- `/` الرئيسية
- `/services` الخدمات
- `/booking` الحجز
- `/gallery` المعرض
- `/location` الموقع
- `/admin` لوحة الإدارة
